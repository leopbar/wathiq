# KYC-POL-002 — Identity documents: Emirates ID

> SYNTHETIC POLICY. Written for this demonstration. It is not a real bank policy and has no
> regulatory standing. Section numbers are invented so that findings can cite something.

## §1.1 Purpose

This policy sets out how an Emirates ID presented for a corporate or personal file is checked
before the file is treated as refreshed. It applies to every signatory, every shareholder with
25% or more of a company, and every authorised representative.

## §1.2 Acceptable copies

A colour scan or photograph of both sides is acceptable. A photocopy of a photocopy, a partial
image, or an image in which the identity number is not legible must be rejected and a new copy
requested. The reason given to the customer must say which part was illegible.

## §1.4 Identity number format

An Emirates ID number has the form 784-YYYY-NNNNNNN-C: the prefix 784, the year of birth, a
seven-digit serial and a single check digit. A number that does not have this shape has either
been misread or does not belong to an Emirates ID, and the document must not be accepted on
the strength of it. Where automated extraction produces a number of the wrong shape, the case
is routed to an officer rather than rejected outright, because the usual cause is a poor scan.

## §1.5 Internal date consistency

The date of birth must be earlier than the issue date, and the issue date earlier than the
expiry date. Dates that run backwards indicate that two fields were read from the wrong parts
of the card, and the whole extraction must be treated as unreliable.

## §1.6 Validity

An expired Emirates ID cannot support a file refresh. Where the card expires within thirty days
the refresh may proceed, and the relationship owner is notified so that a renewed copy is
obtained before the next review.

## §1.7 Names in two scripts

Arabic and English names on the card are two renderings of one name. A difference in
transliteration is not a discrepancy. A difference in the name itself is, and must be resolved
against a second identity document before the file is refreshed.
