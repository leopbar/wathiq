# KYC-POL-004 — Trade licences

> SYNTHETIC POLICY. Written for this demonstration. Not a real bank policy.

## §1.1 Licence number

Every trade licence carries a number issued by the licensing authority. It is the key used to
confirm the licence against the registry, so a licence without a readable number cannot be
accepted and the customer is asked for a clearer copy.

## §2.1 Issuing authority

The licence must name the authority that issued it. Licences from a free zone authority and
from a department of economic development are both acceptable; the authority is recorded on the
file because it determines which registry is queried.

## §3.1 Date consistency

The issue date must precede the expiry date. A licence whose dates run backwards has been
misread, and the extracted values must not be used without an officer confirming them.

## §3.2 Expired licences

A corporate file may not be refreshed on an expired trade licence. This is a mandatory stop:
the case is routed to an officer, who either obtains a current licence or closes the refresh as
incomplete. No automated path may approve a file on an expired licence, whatever the confidence
of the extraction.

## §3.4 Licences close to expiry

A licence expiring within thirty days does not block the refresh. The relationship owner is
notified so that a renewal is obtained before the file goes stale again.

## §4.1 Company name

The company name on the licence is the name the file is held in. Where it differs from the name
on the memorandum of association, the registry is consulted to establish which is the registered
spelling, and the difference is recorded whichever way it resolves.
